# FLYING CARS VIP PROJECT 2026

## Network Team 2026 Github Repo

Our task for this year involves constructing/visualizing a network of flying cars for its use cases. We initially focused on the use case of Rural Emergency Healthcare Access.
We developed an optimizing model to find the minimum number, and the location of vertiports required subject to various parameters, and conducted its
sensitivity analysis.

The required information is in the 'model' tab -- scripts to collect data, optimizing models, and supporting information files
